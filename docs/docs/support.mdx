# Support

## General Support

We provide support via [this repo's issue tracker](https://github.com/Jamyn/dispatch/issues). We do our best to respond in a timely manner, but please keep in mind that open source is not a core responsibility of our job and we provide the code and support on a best effort basis.

## Reporting a Security Issue

We ask that you do not report a security issue to our standard GitHub issue tracker.

If you believe you've identified a security issue with `Dispatch`, please report it privately via [GitHub security advisories](https://github.com/Jamyn/dispatch/security/advisories/new).

> **Note:** The codebase contains no secret values. Development secrets are generated locally by `docker/dev-setup.sh` into a gitignored `docker/.env`; the committed `docker/.env.example` carries only placeholders.

## Supported Versions

This is a single-maintainer, best-effort project with no SLA, but reports are read and acted on. Bug and security reports are accepted against the **latest tagged release** and the current `main` tip only — see [SECURITY.md](https://github.com/Jamyn/dispatch/blob/main/SECURITY.md) for the full policy.
