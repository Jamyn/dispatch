# Configuring Zoom

:::info
Dispatch ships with Zoom conference support. The Zoom plugin creates a conference call with a valid time of 6 weeks and generates a password to protect the call. The Web URL returned by the plugin to the messaging is created such that you need to click it and not worry about entering the password.
:::

:::caution
Zoom disabled JWT app authorization on 2023-09-01 in favor of Server-to-Server OAuth. The setup steps below (JWT app creation) can no longer be completed on the Zoom Marketplace, and the plugin's own auth code (`generate_jwt()` in `dispatch_zoom/client.py`) still implements the removed JWT flow, so this plugin cannot currently authenticate against the live Zoom API. Tracked for a code + doc fix together; see [Jamyn/dispatch#70](https://github.com/Jamyn/dispatch/issues/70).
:::

## Dispatch Configuration

The Zoom plugin is configured in the Dispatch Web UI under Settings -> Project -> Plugins. Add the plugin using the `NEW` button and then edit its configuration by clicking on the three vertical dots.

### Zoom API User Id

> Email / User ID attached to the API credentials.

### API Key

> API Key. (Currently a JWT app key — see the caution above.)

### API Secret

> API Secret. (Currently a JWT app secret — see the caution above.)
