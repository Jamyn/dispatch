# Configuring Jira

:::info
Dispatch ships with Jira support. Each Jira installation is unique, so you will likely want to create a Jira-specific plugin for your organization. This plugin is not required for core functionality. However, a plugin of type `ticket` must always be enabled.
:::

## Dispatch Configuration

The Jira plugin is configured in the Dispatch Web UI under Settings -> Project -> Plugins. Add the plugin using the `NEW` button and then edit its configuration by clicking on the three vertical dots.

### Default Project Id or Key

> Defines the default Jira Project to use. You can find the Jira project id like [this](https://community.atlassian.com/t5/Jira-questions/JIRA-Project-ID/qaq-p/193094) or like [this](https://confluence.atlassian.com/jirakb/how-to-get-project-id-from-the-jira-user-interface-827341414.html).

### Default Issue Type Name

> Defines the default Jira issue type name to use.

### Hosting Type

> Defines the type of deployment (`cloud` or `server`). Defaults to `cloud`.

### Username

> Username to use to authenticate to the Jira API.

### Password

> Password to use to authenticate to the Jira API.

### API URL

> This URL is used for communication with the Jira API.

### Browser URL

> This URL is used to construct browser weblinks.
